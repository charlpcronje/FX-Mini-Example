2 Load a module as a global — .options({ global })

The @-prefix loads the file synchronously; .options({ global }) invokes the plugin factory and publishes its API on the global name.

// plugins/greeter.js default-exports (fx,opts) => api
$$("@/plugins/greeter.js").options({ global: "$greeter" });
$greeter.hello("FX");

3 Mount a module onto a node — node.path@/file

Prefix the spec with a node path to graft the module's namespace onto that node and expose a global.

$$("app.tools@/plugins/greeter.js").options({ global: "$tools" });
// now both $tools and the node app.tools carry the module

4 Class graft — .as(Client)

Load a class module, then .as(Ctor) grafts it onto the node: sets the node type, registers its methods, and maps every instance field to a reactive sub-node with two-way sync. Edit the fields — fullname() recomputes live.

// models/Client.js default-exports class Client { fullname() {…} }
const Client = $$("@/models/Client.js").ns.default;
const client = $$("app.client").as(Client);   // first/last → reactive sub-nodes
$$("app.client.first").set("Grace");       // client.fullname() updates

6 Two-way bind shorthand — $("#el", $$(node))

Pass an FX node as the second argument to $() and the element binds both ways: edits flow into the node, and $$(node).val(v) flows back to the element.

$("#field", $$("bind.demo"));   // two-way in one line
$$("bind.demo").val("set from code"); // updates the input
$$("bind.demo") →

7 Node links — grafted methods through a link

Pass a node as a value to link one node to another. Grafted methods resolve through the link, and it stays live.

$$("app.client").as(Client);              // graft (panel 4)
$$("app.mirror", $$("app.client"));      // LINK mirror → client
$$("app.mirror").fullname();            // method through the link
$$("app.mirror.fullname")();           // …or via the sub-path

8 Declarative templating auto-hydrated

Everything below is straight in index.html — no JS wires it. On load, fx-mini hydrates $${…} interpolation (with | defaults & nesting) and <import>. Type in the box — the interpolations update reactively.

greeting: $${"tpl.name" | "Anonymous"}
nested default: $${"tpl.name" | $${"tpl.alt" | "(fallback)"}}
from <import global="$who">: {$who.first} {$who.last}
