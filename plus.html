FX Mini Plus

Everything FX Mini does, plus the whole everyday jQuery API, WAAPI effects, sync $.ajax, computed nodes, keyed list rendering, persistence and undo/redo — all still synchronous. Open app-plus.js for every call below.

1 Reactive todo — bindEach + $list + $computed + $persist + $history

Keyed diffing (unchanged rows keep their DOM), one-line persistence (reload the page!), and time travel. Stats are a computed node bound with plain .text().

$("#todoList").bindEach("todo.items", { render, key: t => t.id, empty });
$list("todo.items").push({ id, text, done: false });   // every watcher fires
$computed("todo.stats", ["todo.items"], items => `${items.filter(t => !t.done).length} open`);
$persist("todo.items");  $history.track("todo.items");

    2 Effects — jQuery API on the Web Animations engine

    Queued per element, chainable, synchronous calls. .stop() freezes mid-flight; reduced-motion users get instant states.

    $("#fxbox").fadeOut(400).fadeIn(400).slideUp(300).slideDown(300);   // queue!
$("#fxbox").animate({ width: "+=80", opacity: 0.4 }, 500, () => …);

    3 Node-first HTTP — $$("node@url").get()

    FX grammar: select the binding, act on it. The parsed body is the return value AND grafts onto the node — every binding updates (the list below renders via bindEach). Inside handlers it rides the kernel's FXSuspend/replay, so the UI thread is never blocked and requests fire exactly once. $.ajax/$.get remain as jQuery-compat shims.

    const data = $$("api.team@/data.json").get();     // suspends, fills node, returns body
$$("app.saved@/api/save").post({ name: "Ada" });  // the argument IS the payload
$.ajaxSetup({ schema: { template: "envelope" } }); // response template, app-wide
$("#pageHost").load("/page.html section");        // classic .load, selector filter

      5 jQuery parity — creation, traversal, events with namespaces

      $("<li>") creation, .appendTo, .filter/.odd, .one, .hover, and .off(".ns") namespace teardown — the muscle-memory API, reactive underneath.

      $("<li>chip</li>").appendTo("#parityList");
$("#parityList li").odd().addClass("hot");
$(document).on("click.demo", "#parityList li", fn);  $(document).off(".demo");

        6 Snippet libraries — $(selector, context)

        The second argument of $ is where to select: an HTML string parses into an inert <template> and selections come back as clones — so one file holds many snippets, loaded once (the @-loader caches), stamped forever. An FX node as the second argument still means two-way bind.

        const snippets = $$("@/snippets.html");              // one sync load, cached
$("#user-card", snippets).removeAttr("id").appendTo("#snipHost");
$("section", $("#outer", snippets));                // select inside a stamp

        7 Components on the graph — fxc

        Real web components declared in plain HTML (components.html), with lifecycle hooks (mount/unmount/propChange), light-DOM slots, this:-scoped styles without shadow DOM — and props that ARE graph sub-nodes: $$("fxc.badge.hero.label").set("v2") updates every stamp.

        $fxc.load("/components.html");                // sync, cached — registers <fxc-badge>, <fxc-stat>
$('<fxc-badge $label="beta" $node="badge.hero">').appendTo("#cmpHost");
$$("fxc.badge.hero.label").set("v2");          // prop = sub-node → DOM updates

        8 Your old plugins still work — $.fn bridge

        Classic jQuery plugin authoring registers on every handle and group, and can use the reactive methods inside.

        $.fn.flash = function (color) {
  return this.animate({ backgroundColor: color }, 150).animate({ backgroundColor: "" }, 300);
};
